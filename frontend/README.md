# Front-end — SIAC-UTFPR

## Tecnologias

O desenvolvimento do Front-end utilizará:

- **React 18:** biblioteca para construção da interface.
- **Vite:** ferramenta de criação e execução do projeto.
- **TypeScript:** tipagem estática.
- **Tailwind CSS:** estilização da interface.
- **shadcn/ui:** biblioteca de componentes visuais.
- **Zod:** validação de dados e formulários.

## Estrutura

O Front-end será desenvolvido separadamente do Back-end, consumindo sua API REST disponibilizada pelo Django.

## Orientações de desenvolvimento

- Criar uma branch própria a partir da `develop`.
- Não realizar alterações diretamente na `main` ou `develop`.
- Utilizar Pull Requests para integrar alterações à `develop`.
- Manter a organização dos componentes e páginas.
- Centralizar a comunicação com a API do Back-end.

## Observação

A configuração inicial do React com Vite e a instalação das dependências serão realizadas pelo responsável pelo Front-end.
